# Espace client FORMA — archive de production

Cette version est restaurée depuis la distribution publique compilée et vérifiée conservée dans l’historique Git (`b75a96a`, `forma-public-build`). Il ne s’agit pas d’une reconstruction React : le bundle de production et ses ressources d’origine sont servis tels quels. Les chemins absolus ont été adaptés au sous-chemin `/original-client/` pour cohabiter avec le site actuel.

Le rapport `_CAPTURE_REPORT.json` documente l’origine et les limites : les sources TypeScript originales et source maps n’étaient pas disponibles.
